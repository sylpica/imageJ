# ImageJ 学習・実務リファレンス

ImageJ / Fiji を使いながら疑問を解消し、原理を理解するための日本語リファレンスアプリです。無料・ログイン不要の静的サイト（ビルド不要）。

- 公開URL: https://sylpica.github.io/imageJ/
- リポジトリ: sylpica/imageJ

## 構成（6モード＋横断検索）
- **レッスン（28本）**: 概念→原理→ImageJでの意味→具体例→よくある誤解、の構造。SVG図解つき
- **問題（63問）**: 操作暗記ではなく原理の理解と手法の判断を問う四択。全問に正解理由＋誤答理由の解説。出題・選択肢シャッフル、ブックマーク、間違い復習、カテゴリ別演習、学習履歴
- **ドキュメント（12章・51項目）**: 公式ドキュメントの日本語リファレンス。本文は公式資料をもとにした独自の要約・解説で、各項目に出典・原文URL・対象バージョンを明示（公式文書の翻訳・転載ではありません。権利処理の詳細は AUDIT2.md）
- **関数リファレンス（112件）**: ImageJマクロの組み込み関数を分類別に収録。書式・説明・戻り値・使用例・注意を公式「Built-in Macro Functions」に基づく独自要約で示す
- **マクロ練習**: 関数リファレンスを見ながら同じ画面でマクロを書けるエディタ。関数の書式・使用例をワンクリックで挿入、コード中の関数名ダブルクリックで説明表示、テンプレート10種（基礎5・実務5、全種に用語リンクつきの解説と改造ポイント）、下書きの自動保存、.ijmファイルへの保存に対応（実行はImageJ/Fiji本体で行う）
- **実行シミュレーション**（マクロ練習内）: 実行はせず、コードを解釈して「何が起きるか」を自然言語の手順で説明する。モデル画像 demo.tif（512×512・8ビット・画素値の分布つき）を前提に、閾値の前景割合・二値化後の画素値の変化表・Log出力・変数と画像の最終状態を予測する。未知の関数・引数の数・未定義変数・画像なしの操作・無限ループ等は、行番号と原因つきで診断する。表示は「実行ボタンで表示」と「自動で表示（入力に連動）」の2モード（設定は保存される）。詳細は AUDIT6.md
- **用語集（80語）**: 日本語名・英語名・別名・詳しい解説・混同注意つき。本文中の用語はタップ/クリックでポップアップ表示
- **横断検索**: 全モードを一括検索。表記揺れ・同義語・英語に対応（例：しきい値＝閾値＝threshold）

学習記録はブラウザの localStorage（キー `ij-ref-v2`）にのみ保存されます。旧バージョンの保存データとは互換性がありません。

## ローカルで開く
`index.html` をブラウザで開くだけで動作します。

## テスト
```
node tests/validate.mjs   # データ整合性・参照・選択肢バイアス・公式関数一覧との照合
node tests/audit.mjs      # Playwright による実ブラウザ監査（375px / 1280px）
```
